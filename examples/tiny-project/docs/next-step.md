# Add an item

## Current task
Specify the smallest useful add-item flow before implementing it.

## Acceptance criteria
- A nonempty title is required.
- A link is optional.
- New items start as unread.
- Duplicate-link behavior is agreed and covered by an example.

## First action
Choose duplicate-link behavior with the project owner. Then add an acceptance example for a title without a link.

## Scope
No login, cloud sync, importing, or external API.
